Relational DB Design

ແຜນຜັງຄວາມສຳພັນຖານຂໍ້ມູນ (Entity Relationship Diagram - ERD)

tbl_delegations

org_name_lao / eng
country_name

head_of_delegation
1:N

FK delegation_id
visit_date (YYYY-MM-DD)
meeting_topic
doc_category
created_at / updated_at
N:M

PK exec_id
exec_title (ອະທິການບໍດີ...)
exec_name

PK media_id

file_path_pdf
file_path_photo
1. ຕາຕະລາງ `tbl_visits` (ກິດຈະກຳການຕ້ອນຮັບ) Primary Table
  • • id: VARCHAR(20) [PK] - ລະຫັດກິດຈະກຳ (VIS-2026-001)
  • • date: DATE - ວັນທີຕ້ອນຮັບ (YYYY-MM-DD)
  • • type: ENUM('ຕ່າງປະເທດ', 'ພາຍໃນ')
  • • country: VARCHAR(100) - ຊື່ປະເທດ
  • • topic: TEXT - ເນື້ອຫາ/ຫົວຂໍ້ການພົບປະ
2. ຕາຕະລາງ `tbl_mou_agreements` (ສັນຍາ MOU/MOA) Contract Module
  • • agreement_id: INT AUTO_INCREMENT [PK]
  • • visit_id: VARCHAR(20) [FK] -> tbl_visits.id
  • • doc_type: ENUM('MOU', 'MOA', 'Extension', 'Minutes')
  • • doc_path: VARCHAR(255) - ລິ້ງເອກະສານ PDF
  • • photo_path: VARCHAR(255) - ລິ້ງໂຟເດີຮູບພາບ
