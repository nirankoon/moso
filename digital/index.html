ສື່ທີ່ເພີ່ມລ່າສຸດ

ລາຍງານສະຖິຕິການຈັດເກັບສື່

ສະຫຼຸບຂໍ້ມູນການອັບໂຫຼດ ແລະ ປະເພດສື່ໃນລະບົບ

ສະຖິຕິແຍກຕາມໝວດໝູ່ສື່

ຈຳນວນສື່ທີ່ຖືກເພີ່ມເຂົ້າລະບົບ

ຕາຕະລາງສະຫຼຸບລາຍງານ (ປະຈຳວັນ)

ຊື່ສື່ ໝວດໝູ່ ແທັກ (Tags) ວັນທີເພີ່ມ ຂະໜາດ

ຈັດການຂໍ້ມູນ (Data Management)

ຂໍ້ມູນທັງໝົດຖືກຈັດເກັບຢູ່ໃນ Web Browser local storage ຂອງເຄື່ອງນີ້ (PC / Mobile)

ສົ່ງອອກຂໍ້ມູນ (Export Data)

ດາວໂຫຼດຂໍ້ມູນສື່ທັງໝົດອອກເປັນໄຟລ໌ JSON ສຳລັບການສຳຮອງ (Backup).

ນຳເຂົ້າຂໍ້ມູນ (Import Data)

ເລືອກໄຟລ໌ JSON ທີ່ເຄີຍສົ່ງອອກໄວ້ ເພື່ອນຳເຂົ້າຂໍ້ມູນຄືນມາ.

ລ້າງຂໍ້ມູນທັງໝົດ (Clear All Data)

ລົບຂໍ້ມູນສື່ທັງໝົດອອກຈາກເຄື່ອງຂອງທ່ານ. ການກະທຳນີ້ບໍ່ສາມາດຍົກເລີກໄດ້!
